## ✨ About the Project
Project Atlas is the official developer portfolio of **Harsh Mehta**, an aspiring AI Full-Stack Developer and future tech entrepreneur. Designed with a dark-mode, glassmorphism UI, it aims to reflect a premium SaaS startup aesthetic rather than a standard student portfolio. 

It highlights a journey from learning core programming to integrating Artificial Intelligence into scalable MERN stack applications.

## 🛠️ Tech Stack & Architecture
- **Framework:** React.js (Bootstrapped with Vite for maximum performance)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Integrations:** GitHub API (Dynamic Stats), EmailJS (Contact Form)

## 🎨 Design System
- **Theme:** Strict Dark Mode with smooth gradients, soft blur effects, and premium spacing.
- **Background:** `#030712` | **Cards:** `#111827`
- **Primary:** `#3B82F6` | **Secondary:** `#8B5CF6` | **Accent:** `#06B6D4`
- **Typography:** Modern sans-serif, fully responsive.
